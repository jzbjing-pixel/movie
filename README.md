# Movie · Rill 视频播放器 0.1.1

左侧视频媒体列表，右侧电影播放器。支持多维表或视图片库、搜索、继续观看/已看完筛选、全屏、倍速、快进快退、保存秒时间码和断点续播。

## Git 安装

需要支持公共 Host API 2、media.openStream 和 files.attributes 的新版 Rill。插件管理添加 GitHub 仓库 `jzbjing-pixel/movie`，选择 Git 安装，资源名 `rill-plugin.git.zip`，公钥使用 `publisher.json` 的 publicKey。签名包位于 `dist/rill-plugin.git.zip`。此仓库仅发布签名安装包、公钥和使用说明，开发源码不公开。

首次打开点击“片库设置”，选择电影目录所在的多维表及可选视图。目录由 Rill 多维表连接，插件不自行扫描磁盘。支持 MP4/M4V/WebM/OGV/MOV/MKV 文件识别，实际播放取决于系统 WebView 的编码能力；推荐 MP4/H.264，MKV、HEVC、DTS 不保证可解码。大文件按最多 4 MiB 分段读取，不将整部影片载入内存。

## 观影进度

位置记录为秒。影片加载后读取 watchPosition 并设置播放器 currentTime。播放中每 10 秒保存，暂停、切换电影、结束观影时保存。保存失败会保留当前位置，点击保存重试；若另一个窗口已更新，点击“重新读取进度”采用表中的版本。请点击“结束观影”或“打开多维表”完成保存后离开；强制关闭或杀进程可能丢失最后一次未提交的位置。

观看属性投影在原视频行：watchPosition（观看位置/秒）、watchDuration（总时长/秒）、watchProgress（观影进度/百分比）、watched（已看完）、lastWatched（最后观看时间）。底层为同一表的宿主管理伴随属性文件，不改写电影二进制。支持筛选和读取，更新保留未知属性且检查版本。读写遵守表全局/视图范围，保存不能导致文件离开授权视图。

Android 来源需支持本地文件寻址，非寻址 SAF/远程云文件提供者会报错。首次使用新版宿主能力需要更新 Rill；此包不附带宿主 APK。Android 真机和电影编码兼容性待验收。

验收：真实浏览器样片解码、秒时间码续播、保存冲突、切换释放旧影片、未知属性保留，以及 1280/390/320px 布局通过；宿主权限/撤销回归、原生分段读取/持久化测试、Windows/Android Rust 编译及签名校验通过。

## 0.1.1 更新

区分媒体读取、解码和不支持的源错误。浏览器预览播放需要同步修复宿主的媒体 CSP 地址映射；插件更新本身不能替代宿主修复。保持公共 Host API 2 和原发布者签名。
